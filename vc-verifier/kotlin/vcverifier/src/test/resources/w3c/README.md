# W3C Data Integrity test vectors

These signed credentials are published test vectors used to verify interoperability
with the normative cryptosuite algorithms:

- `eddsa-rdfc-2022-signed.json` comes from W3C CCG `vc-di-eddsa`, commit
  `549929f78f65d60d0516e0757269bfaffb926847`, under
  `TestVectors/eddsa-rdfc-2022/`.
- `ecdsa-rdfc-2019-p256-signed.json` comes from W3C CCG `vc-di-ecdsa`, commit
  `b2f56db452265a663f2b6cf81927ac7024b3e60d`, under
  `TestVectors/ecdsa-rdfc-2019-p256/`.

Sources:

- https://github.com/w3c/vc-di-eddsa
- https://github.com/w3c/vc-di-ecdsa
